# El Catálogo se transcribe de la Carta durante el desarrollo, no dentro de la app

El Catálogo se genera una vez, a partir de fotos de la Carta, y se publica como datos estáticos junto con la app. No se escanea en el celular del usuario. Escanear dentro de la app exigiría cámara, un servicio de OCR o LLM y una API key expuesta en un sitio estático de GitHub Pages, además de una pantalla para corregir errores. Es un producto en sí mismo, desproporcionado para la v1, que es de un solo restaurante.
